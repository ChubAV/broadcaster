# Канонический макет v2.0

`new_broadcaster_design.html` (в корне репозитория) — единственный источник истины дизайна
для всех шести фаз milestone v2.0: токены, шелл, навигация, компоненты, адаптив.

Это **bundled-страница**, а не обычный HTML. Разметка лежит JSON-строкой внутри
`<script type="__bundler/template">`, ассеты — внутри `<script type="__bundler/manifest">`.
Грепать исходник бесполезно — сначала распаковать.

## Файлы

| Файл | Что это |
|------|---------|
| `../new_broadcaster_design.html` | Исходник. Источник истины. Не редактировать. |
| `new_broadcaster_design.unpacked.html` | Распакованная разметка — то, что нужно читать. Генерируется, не редактировать. |
| `new_broadcaster_design.manifest-index.json` | Опись ассетов манифеста (21 шт.: 3 JS + 18 woff2) — id, mime, размер. |
| `unpack.js` | Скрипт распаковки. |

## Перегенерация

```bash
node design/unpack.js
```

## Что важно знать перед чтением

Разобрано в `.planning/phases/01-interfeysnyy-fundament/01-RESEARCH.md`:

- В макете **нет** `:root`, CSS-переменных и `class=`. Всё оформление — 490 инлайн-`style`
  с захардкоженными hex, плюс 58 несуществующих атрибутов `style-hover` и 2 `style-focus`.
  Токены из макета **выводятся**, а не переносятся.
- Дословному переносу подлежат только базовый блок с `@keyframes` и три медиазапроса (~2.8 КБ).
- Space Grotesk объявлен только для latin/latin-ext/vietnamese — кириллицы в нём нет
  (см. D-17 в `01-CONTEXT.md`).
- Данные-примеры разделов лежат в `<script type="text/x-dc">`.
