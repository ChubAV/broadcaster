- **W-1** — локальный бэкфилл не достучится до WA/MAX: `_container_endpoint` строит `http://{container_name}:3000` (`app/services/wa_container_manager.py:147-148`, `app/services/max_container_manager.py:190-191`), имена разрешаются только в сети compose. Докстринг скрипта уже описывает локальный режим как ограниченный для TG; для WA/MAX ограничение не названо. → PHONE-17, PHONE-19.
- **W-2** — в `<option>` фильтров истории и админской истории пользователя нет пометки «указан вручную»: `plain`/`plain_with_id` (`app/services/account_label.py:68-82`) флага не несут. → PHONE-08.
- **W-3** — два аккаунта одного типа без номера оба получают `#id` двойника (`account_label.py:105-111`). По букве PHONE-05 (совпадающие подписи) это допустимо.
- **W-4** — `app/messengers/max.py:195` пишет `error=str(e)` в `start_session_error`, а payload несёт номер. Строки исключений httpx обычно несут URL, не тело; код до вехи, фазами 18–20 не тронут. → PHONE-21.
