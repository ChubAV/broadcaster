# Cookie сессии выставляется без флага `secure`

## Где

`app/pages/auth.py:56`, `:341`.

## Цена

nginx делает 301 с :80 на :443, но cookie уходит в ответе ДО редиректа — то есть
открытым текстом по незашифрованному соединению. HSTS в шаблонах nginx нет, так
что первый запрос браузера по http ничем не предотвращён.

## Что чинить

`secure=True` на обе установки cookie — И проверить, что HTTPS жив на всех
входах, иначе вход сломается целиком (cookie просто не сохранится). Добавить
HSTS в шаблон nginx.

⚠️ Правка трогает боевой вход. Порядок: сперва убедиться в HTTPS, потом флаг.
