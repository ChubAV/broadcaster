<objective>
Гейт чистоты цепи предков перестаёт пропускать четыре доказанных обхода и начинает смотреть туда же,
куда смотрит браузер.

Группа правил, заведённая планом 10-33 против второй половины расхождения Р-3, стережёт настоящее
свойство: подъём, объявленный `position: fixed`, есть подъём ДО ОКНА ровно до тех пор, пока ни один
предок точки включения не порождает содержащий блок и не заводит собственного контекста наложения.
Седьмой круг ревизии показал ИСПОЛНЕНИЕМ, что сегодня гейт этого свойства не держит — тремя
находками и четырьмя воспроизведёнными обходами.

**`WR-05` — перечни запрещённых свойств неполны.** `CONTAINING_BLOCK_PROPERTIES` и
`STACKING_CONTEXT_PROPERTIES` не содержат индивидуальных трансформаций CSS Transforms Level 2
(`translate`, `rotate`, `scale`) и свойств контейнеризации (`container-type`,
`content-visibility`) — всё это отгружено во всех вечнозелёных браузерах, порождает содержащий блок
для фиксированного потомка и заводит контекст наложения ровно так же, как `transform`. Не хватает
также `transform-style: preserve-3d`, `clip-path`, `mask`, `view-transition-name`. Проверено
исполнением на доктóренных копиях боевой таблицы: `[data-body] { translate: 0 10px; }` → находок
НОЛЬ; `[data-body] { container-type: inline-size; }` → находок НОЛЬ.

**`WR-06` — положение читается ПОБЛОЧНО, и ветвь слоя обходится разнесением по двум блокам.**
`position` берётся из ТОГО ЖЕ блока, что и `z-index`; свойства одного элемента в CSS живут в разных
блоках сплошь и рядом, тем более что разборщик уплощает медиазапросы — медиазапросная добавка
становится отдельным равноправным блоком. Проверено исполнением: слой в одном блоке плюс положение
в медиазапросной добавке → находок НОЛЬ. Элемент получает собственный контекст наложения, подъём
запирается внутри него, гейт зелен. Это тот же класс отказа, что `WR-05`, но достижимый БЕЗ единого
свойства из перечней.

**`WR-07` — вселенная предков не содержит корневого элемента и тела документа, которые ЭТА ЖЕ
таблица стилизует.** Между обёрткой шелла и окном стоят ещё два предка, и оба несут объявления в
этом же файле: `body { margin: 0; … }` (`app.css:430`) и `.is-modal-open, .is-modal-open body {
overflow: hidden; }` (`:961-963`). Второе — правило ТОГО ЖЕ состояния, что и подъём, и стои́т строкой
выше него: именно туда потянется следующая правка, а гейт туда не смотрит. Проверено исполнением:
`body { filter: blur(0px); margin: 0; }` → находок НОЛЬ. `filter` на теле документа отнимает у
подъёма окно ЦЕЛИКОМ, и правило молчит.

Purpose: расхождение Р-3 — «человеку на отказе не показано ни одного объяснения» — закрыто подъёмом,
и подъём стерегут два правила. Но правило, которое можно обойти четырьмя способами, из которых два
достижимы одной строкой в соседнем блоке того же файла, есть обещание, а не защита; а гейт,
пропускающий свойство молча, хуже отсутствующего — он вводит следующего читателя в заблуждение
ровно в тот момент, когда тот полагается на зелёный прогон.

Output: перечни, накрывающие все названные ревизией классы; сборка объявлений по предку, а не по
блоку; вселенная, совпадающая с настоящей цепью до окна; и четыре отрицательных контроля, каждый из
которых воспроизводит СВОЙ доказанный обход.
