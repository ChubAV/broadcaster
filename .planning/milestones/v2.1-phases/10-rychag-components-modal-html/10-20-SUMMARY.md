## ЗАМЕР ЗУБОВ — ПРОГОНОМ, А НЕ ОБЪЯВЛЕНИЕМ

### Правило видит ОБА терминальных состояния (половина «а» контроля, по каждому элементу перечня)

Зонд подменял поле состояния `10-UAT.md` **В ПАМЯТИ** (файл дерева не правился ни на символ):

```
ЗОНД state=complete: находок 1 -> `…/10-UAT.md`: состояние `complete` ТЕРМИНАЛЬНО (совпало
  с элементом объявленного перечня), то есть артефакт объявил обход закрытым, — а таблиц
  отметок у него 6 при 0 заполненных…
ЗОНД state=passed:   находок 1 -> `…/10-UAT.md`: состояние `passed` ТЕРМИНАЛЬНО … 6 при 0 …
```

**Нарушение найдено И на `complete`, И на `passed`.** Без вывода по `complete` доминирующая в дереве форма вошла бы в правило непроверенной.

### Почему ПЕРЕЧЕНЬ, а не один литерал — измерено, а не заявлено

```
зонд «перечень сужен до одного литерала»: находок 0 — правило МОЛЧИТ на доминирующей форме
тот же вход при ПОЛНОМ перечне: находок 1
```

Синтетический артефакт в состоянии `complete` с пустыми отметками проходит гейт беспрепятственно, если перечень сведён к `{"passed"}`. Это и есть повторение коммита класса `0ea886d` при живом принуждении.

### Правило зелено в ОБОИХ законных состояниях (половины «б» и «в»)

| Половина | Вход | Находок |
|---|---|---|
| (а) терминальное состояние + ПУСТЫЕ отметки | по каждому из 2 элементов перечня | **1** на каждом |
| (б) терминальное состояние + ЗАПОЛНЕННЫЕ отметки | по каждому из 2 элементов | **0** |
