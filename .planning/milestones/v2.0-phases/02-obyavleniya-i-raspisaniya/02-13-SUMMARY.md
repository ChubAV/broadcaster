# Phase 02 Plan 13: Очередь вместо отмены на форме автосохранения (CR-04) Summary

Замена hx-sync стратегии отмены на `this:queue last` на форме #ad-form: наложение «автосохранение в полёте + Сохранить» больше не выбрасывает ответ с идентификатором черновика — одна строка ads, published, без сирот.

## RED (что было красным и почему)

Коммит `6e78267` — `test(02-13): контракт очереди автосохранения и регрессия наложения`.

- **Красным** был перевёрнутый контракт разметки `test_editor_form_carries_autosave_and_stays_a_real_form`: он утверждает `hx-sync="this:queue last"` в отрендеренном редакторе и отсутствие `this:replace`, а разметка на тот момент ещё несла стратегию отмены (form.html:57). Причина красноты — ровно «разметка ещё несёт отмену», как требует гейт.
- **Зелёной сразу** была новая именованная регрессия `test_save_during_autosave_overlap_lands_in_one_published_ad` — ожидаемо и предусмотрено планом: серверная половина закрыта планом 02-08, тест закрепляет КЛИЕНТСКИЙ секвенс очереди на сервере: (1) POST /ads/new без `ad_id` («текст до нажатия»), (2) идентификатор извлекается из ТЕЛА ответа — из внеполосного блока `#ad-id-field` (autosave_response.html:34), как браузер подменяет поле до переиздачи очереди, (3) второй POST с извлечённым `ad_id`, `save="1"`, «текстом на момент нажатия» и двумя ключами `images` (путь requestSave(), SC-2), (4) ровно одна строка ads (`_only_ad` через `.one()`), `AD_STATUS_PUBLISHED`, текст и вложения второй сериализации в порядке отправки.

## GREEN (одно изменённое значение атрибута)

Коммит `2bf4e2f` — `feat(02-13): очередь вместо отмены на форме автосохранения (CR-04)`.

- Единственное функциональное изменение: значение атрибута `hx-sync` формы `#ad-form` (app/templates/ads/form.html) переведено на `this:queue last`. Остальные атрибуты (`hx-post`, `hx-trigger="submit, keyup changed delay:2s, change delay:2s"`, `hx-swap="none"`, `method="post"`, `action`) байт-в-байт не тронуты (D-05, D-06, D-09).
- Головной комментарий формы дополнен абзацем-обоснованием очереди; прежнее значение атрибута описано словами «стратегия отмены», не литералом — иначе контракт разметки сорвался бы на тексте комментария.
- После правки: `uv run pytest -q tests/test_pages/test_ads_editor.py tests/test_templates/test_ads_form_security.py` — **41 passed** (контракт разметки и регрессия наложения зелёные, шесть тестов способа сборки клиентской разметки не задеты, базовый путь без JS — 302 — зелёный).
