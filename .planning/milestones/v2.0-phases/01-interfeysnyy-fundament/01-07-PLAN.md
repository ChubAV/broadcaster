## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| обычный пользователь → адреса админки | Попытка доступа к административным страницам |
| данные пользователей → HTML админки | Персональные данные в списке пользователей |
| внешний мессенджер → справочник групп | Названия групп из внешних систем |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Elevation of Privilege | админ-страницы | high | mitigate | Проверка прав остаётся в обработчиках и не переезжает в шаблон; пункт навигации админки остаётся под проверкой прав в шелле. Поведенческий тест `test_admin_denied_for_regular_user` фиксирует отказ обычному пользователю |
