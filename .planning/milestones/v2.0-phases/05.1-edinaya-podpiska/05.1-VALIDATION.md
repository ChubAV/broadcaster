## Sampling Rate

- **After every task commit:** `uv run pytest <затронутый файл> -q -x` (< 30 s)
- **After every plan wave:** `uv run pytest tests/test_pages tests/test_services tests/test_application tests/test_migrations -q` — this is the phase's blast radius
- **Waves touching the worker or the migration additionally require:** `uv run pytest tests/test_worker tests/test_migrations -q` — the two irreversible risks (ungated send window, one-way-door migration) live there
- **Before `/gsd-verify-work`:** `just test` fully green
- **Max feedback latency:** 30 s
