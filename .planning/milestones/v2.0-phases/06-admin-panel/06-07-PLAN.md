<objective>
Подраздел «Очередь» отвечает на один вопрос — что ждёт отправки прямо сейчас — по каждому
из трёх каналов, и даёт снять одну конкретную задачу.

Purpose: сегодня содержимое очередей не видно нигде: воркеры читают их сами, а внешний
инструмент знает только один канал из трёх и поднят без аутентификации. Подраздел
обнажает и то, чего в проекте нет: у канала telegram нет ни повторов, ни отложенности —
и именно поэтому его строка обязана показывать другое, а не притворяться, что показывает
то же самое.

⚠️ ГЛАВНАЯ ЛОВУШКА ПЛАНА НЕ ПАДАЕТ. Два канала пишут отложенность задачи в РАЗНЫХ
единицах времени, каждый читает своё значение своей меркой и потому работает. Подраздел
читает оба списка одним кодом — и единая формула нарисует правдоподобную ложь на одном из
двух каналов, без исключения и без 500. Разбор обязан быть по каналу и закреплён тестом на
обоих телах задач.

Output: прикладной разбор строки очереди, чтение и снятие через сервис оперативного
состояния, подраздел с тремя каналами и снятие одной задачи через панель подтверждения.
</objective>
