## Номер в CSV-экспорте

Находка разведки кода: номер начинается с `+`, а `export_cell` (`app/pages/history.py:236`)
ставит апостроф перед любой ячейкой на `+`. Критерий 4 роадмапа требует «прежнее обезвреживание
формул», то есть в файле получилось бы `'+7 999 123-45-67`.

| Option | Description | Selected |
|--------|-------------|----------|
| С апострофом (Рекомендуется) | Как требует критерий 4: номер проходит ту же защиту, что и все ячейки; в Excel виден апостроф | |
| Без «+», только цифры | В файле `7 999 123-45-67`: апострофа нет, защита не обходится, но номер в файле отличается от экрана (отступление от D-30) | ✓ |
| Исключение из защиты | В файле `+7 999 123-45-67`; колонка идёт мимо обезвреживания — исключение из T-04-16 | |

**User's choice:** Без «+», только цифры
**Notes:** Рекомендация была «с апострофом»; владелец выбрал убрать знак. Записано как D-09.
