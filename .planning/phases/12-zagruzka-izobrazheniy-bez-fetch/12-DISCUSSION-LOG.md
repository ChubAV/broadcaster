## Деградация без JS

Область не была в исходном перечне — всплыла при разборе кода: `#file-input` (`form.html:162`)
не имеет атрибута `name`, то есть прикрепить картинку без JavaScript сегодня невозможно.

| Option | Description | Selected |
|--------|-------------|----------|
| Остаётся невозможным | Состояние не меняется и объявляется ИМЕНОВАННЫМ изъятием в реестре (как D-08 Фазы 11 для 403). Фаза не выдумывает возможности, которой не было | ✓ |
| Начинает работать | Форма загрузки — настоящая `method="post"` с кнопкой отправки. Цена: несохранённый текст теряется — без JS автосохранения тоже нет | |
| Через форму объявления | Файловое поле получает `name` и `form="ad-form"`, файлы едут с «Сохранить», текст не теряется. Цена: обработчик сохранения учится принимать файловые части — ровно то, что он сегодня отвергает осознанно (`ads.py:537`, WR-03) | |

**User's choice:** Остаётся невозможным.
**Notes:** Стало D-09. Формулировка уточнена ПОСЛЕ выбора, по механизму: htmx отправляет поля
по имени, поэтому `name` у файлового поля появится. Изъятие держится отсутствием кнопки отправки
и недостижимостью пути из интерфейса, а НЕ безымянностью поля. Уточнение внесено в CONTEXT.md
явным предупреждением планировщику.

## Claude's Discretion

Решено по умолчанию, владелец делегировал явно:

- **D-07** — механика потолка: `hx-include` текущих ключей, сверка принадлежности и потолка
  существующим `own_image_keys`, своп `innerHTML` в `#media-strip`, исчезновение `#image-inputs`.
- **D-08** — текст отказа внутри фрагмента, `#upload-error` снимается (ловушка G-11 Фазы 9).
- **D-11** — порог счётчика читается из числа плиток в разметке вместо `imagePaths.length`.
- **D-12** — состав снимаемого и судьба трёх держателей: render-тест `UPLOAD_TYPE_ERROR`
  снимается вместе с копией; `UPLOAD_TRANSPORT_ERROR` растворяется в плашке `htmx:sendError`;
  `IMAGE_BASE_URL`/`THUMB_KEY_PREFIX` — проверить читателей, а не предположить.
- **D-13** — форма учёта инвентарных чисел (`fetch(` 6→1, оба перечня 5→4).
- **D-14** — адресация чужого долга R-08-02 Фазе 13.

Не решено нигде и оставлено планировщику: точное написание адреса маршрута, имя файлового поля,
имя и расположение шаблона фрагмента, элемент для `hx-indicator`, разбиение на планы и волны.
