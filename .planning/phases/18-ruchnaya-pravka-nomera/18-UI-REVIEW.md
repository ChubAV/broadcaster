## Три приоритетных исправления (текущие)

1. **Ручная пометка неотличима от автоматического номера при узкой ширине** (UI-R-04) — на 320 и 375 px пометка «указан вручную» уходит первой, а полного текста с ней нет: `title=` чипа строится из `labels[acc.id].plain` (`ads/includes/sched_card.html:226`), у `<h2>` `title=` нет (`account_groups/list.html:59`). Человек видит «Telegram +7 999 123-45-67» и не знает, введён ли номер руками. Исправление: добавить полную форму с пометкой для `title=` чипа и для `<h2>` (отдельный помощник, не `plain`); это исключение из D-10 («в плоских формах пометки нет») требует решения владельца. Пока решения нет — записано как открытое.

2. **Вторичный текст «Номер неизвестен» и `#id` двойника ниже нормы контраста** (UI-R-21) — `.mono--muted` (`app.css:858`) берёт `--text-muted` (`app.css:47`): 3,61:1 на `--surface`, 3,76:1 на `--bg`, 11 px. Это тот же токен, который Фаза 17 назвала дефектом; гап-раунд исправил пометку отдельным токеном (`--text-secondary`), а общий токен оставил, «отложено до решения владельца» (комментарий `app.css`, блок пометки). Исправление: `.mono--muted { color: var(--text-secondary); }` (одна строка, проверка на всех экранах с `.mono--muted`) либо новый токен не ниже 4,5:1. Одна строка, но меняет все экраны — нужно решение владельца.

3. **Поле номера не связано с текстом ошибки для вспомогательных технологий** (UI-R-13) — `components/field.html` ставит `aria-invalid="true"` (строка 26), но `aria-describedby` не ставит и параметра для него не имеет; имя поля собирается из подписи, подсказки и ошибки разом. Человек с читалкой слышит «Номер телефона Пример: … Не похоже на номер…», не получая связи ошибки с полем. Исправление: в макросе `field` добавить параметр id для подсказки и ошибки и печатать `aria-describedby` на `<input>`; макрос общий для всех экранов авторизации и профиля, поэтому нужен отдельный решение владельца (владелец в гап-раунд его не включал).

## Ручная проверка (declared human items)

Всё ниже не измерено в этом аудите. Ни одна строка не заявлена как измеренная. Для `/gsd-verify-work 18`:
