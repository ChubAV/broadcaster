## Два прочтения, записанные, чтобы верификатор не искал противоречия

**D-12(в) и шаблон мастера MAX.** D-12(в): «В шаблоны `accounts/*` фаза НОВЫХ свопов не приносит (D-02:
оба действия синхронизации — `HX-Location`), поэтому тройная копия разметки карточки аккаунта в этой
фазе не сводится». Предмет абзаца — три шаблона КАРТОЧКИ аккаунта и два действия синхронизации. D-02
для `accounts_connect_max_start` прямо назначает «фрагмент контейнера шага мастера (постоянный id)».
Шаблон мастера `accounts/connect_max.html` карточкой не является, и своп в его контейнер исполняет D-02,
не нарушая D-12(в).

**Адрес деградации старта MAX** (усмотрение планировщика — D-02 его не назначает). `respond()` требует
адрес перенаправления; сегодня путь без JavaScript получает страницу QR прямо в ответ на POST. Измерено
чтением кода: подключение завершает ТОЛЬКО опрос htmx `accounts_connect_max_status`, то есть без
JavaScript мастер не завершается и сегодня; GET `/accounts/connect/max` удаляет аккаунты в статусе
`connecting`. Приземление на `/accounts` сохраняет заведённую запись и не отнимает ни одной работающей
возможности. Решение обратимо (`reversible`) и названо в докстринге обработчика.
</decision_reading>
