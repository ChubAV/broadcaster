D-03: «Постоянный id получает только блок действий `admin/user_detail.html`. `admin/includes/worker_row.html`
и `queue_row.html` в этой фазе id и макросов НЕ получают… id без потребителя-свопа ничего не
добавляет». D-02 для этих же тумблеров требует «OOB для прочих мест страницы, печатающих то же
состояние», а §Claude's Discretion отдаёт состав этих областей планировщику. Внеполосная подмена
содержимого требует id цели. Прочтение: «только» в D-03 противопоставлено трём файлам
`admin/includes/*` роадмапа, а основание D-03 («id без потребителя-свопа») прямо разрешает id
областям, у которых потребитель-своп ЕСТЬ. Поэтому id получают ровно две области состояния и блок
действий, строки воркеров и очереди — нет. Запись повторяется шапкой шаблона ответа.
