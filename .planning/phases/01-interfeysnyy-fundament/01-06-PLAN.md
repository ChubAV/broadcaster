Механизм, который здесь легко разрушить, не заметив: опрос статуса не имеет команды «стоп». Он
прекращается тем, что очередной ответ приходит **без** атрибутов запроса и триггера — они обёрнуты
условием по статусу прямо в разметке. Соблазн при переверстке — вынести запрос на внешний элемент

синхронизации. Признак в эксплуатации — непрекращающийся поток запросов статуса в логах.

Поэтому: условие вокруг HTMX-атрибутов переносится как есть; атрибуты остаются на том же элементе,
который заменяется целиком; идентификатор якоря сохраняется.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| браузер → мастера подключения | Номер телефона, код подтверждения и пароль двухфакторной защиты пересекают границу |
| внешний мессенджер → приложение | Имена аккаунтов, тексты ошибок и статусы приходят из внешних систем |
| браузер → опрос статуса | Повторяющиеся запросы без действия пользователя |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
