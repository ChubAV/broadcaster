### 2. Арифметика шага стопки, снятая ПРАВИЛОМ с таблицы

```
  + отступ сверху и снизу (padding × 2): 22.0px      ← .alert { padding: 11px 14px }
  + рамка сверху и снизу (border × 2): 2.0px          ← .alert { border: 1px solid transparent }
  + 3 строки (line-height 1.5 × font-size 13.0px): 58.5px   ← .alert + :root { --fs-md: 13px }
  + зазор между плашками (8px): 8.0px
  = минимум: 90.5px; объявлено: 96px
```

Число строк — ТРИ при замеренных двух: самое узкое ОБЪЯВЛЕННОЕ рабочее окно таблицы 400px, ширина плашки `min(560px, 400−24)` = 376px, поле набора 346px, текст плашки отказа сервера 55 знаков при кегле 13px → две строки. Третья есть НАЗВАННЫЙ запас, а не округление итога. Зазор 8px — меньшая из двух соседних величин вертикального ритма таблицы (8px и 9px); шкалы отступов у проекта нет вовсе.
