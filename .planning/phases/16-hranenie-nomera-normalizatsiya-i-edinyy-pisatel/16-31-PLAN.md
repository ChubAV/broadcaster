## Решения планирования

- **Ось одна на оба гейта — один план.** Строки повторного связывания ложатся в общий `BINDING_FORMS`; их
  обходят обе матрицы и правило-паритет. Добавить строки и починить один гейт значило бы оставить суиту
  красной между планами.
- **Подменное значение — поле значения опознания, а не строка формы.** Ошибка WR-18 проявляется, только когда
  подмена того же вида, что значение: пишущий API, первый по алфавиту (`bulk_update_mappings` против
  `set_committed_value`), — у имени, атрибута и `getattr`-строки; `partial` над другим API — у `partial`;

  пустая строка, позиционное создание прежних строк не ломается), а форма — место `{decoy}`.
- **Дедупликация по (строка, столбец, вид).** Имя, связанное с двумя пишущими API, судится как каждый; один
  вызов — одна находка. Предмет — первой находки в порядке обхода целей.
- **Цена — в сторону лишней находки.** Имя, перевязанное с пишущего API на безобидное (`w = setattr`, потом
  `w = print`), судится и как API; это та же цена плоской области видимости, что абзац цены уже называет, и
