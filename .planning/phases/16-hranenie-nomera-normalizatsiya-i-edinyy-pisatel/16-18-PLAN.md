## Аудит прежней «ГРАНИЦЫ СРЕДСТВА» (довод «нельзя опознать ни по фабрике, ни по имени журнала, ни по ввозу»)

| Пункт границы 16-13 | Довод правдив? | Решение плана |
|---------------------|----------------|---------------|
| получатель — параметр функции (`def f(lg): lg.info(…)`) | да — тип по исходнику не назван, поток данных | остаётся в границе |
| обёртка `logging.LoggerAdapter(logger, …)` | нет — класс модуля `logging`, создающий журнал | ловится: фабрика (`LOGGER_FACTORIES`) |
| `functools.partial(logger.info, …)` | нет — ссылка на метод опознанного журнала | ловится: вызов-ссылка и имя, связанное с ним |
| `getattr(logger, "info")(…)` | нет — опознанный журнал и метод строкой | ловится; `getattr(logger, name)` с вычисленным именем — граница |
| второе связывание `a = lg` | нет — связывание в модуле, как у `_module_model_aliases` гейта писателя | ловится: присваивание опознанного получателя |
| журнал из контейнера / атрибута чужого объекта | да — поток данных | остаётся в границе |
| фабрика под псевдонимом ввоза (`getLogger as gl`) | нет — опознаётся по ввозу | ловится: `ModuleLogNames.factories` |
| привязка через `getattr(…, "bind_contextvars")` | нет — имя привязки строкой | ловится |
| привязка через `importlib` | пункт неверен по сути: `importlib.import_module("structlog.contextvars").bind_contextvars(…)` ловился всегда — по последнему имени вызова (замер) | из границы убирается с летописью |
| одна область видимости — модуль | цена, а не слепота | остаётся как цена |

## Решения планирования

- **Где граница D-17.** Опознание — по ввозу из `logging`, по фабрике (`LOGGER_FACTORIES`, их псевдонимам
  и обёрткам-фабрикам), по связыванию в модуле (присваивание, аннотированное присваивание, `:=`, тело
  класса, второе связывание) и по ссылке на метод опознанного журнала. Имя с методом `.info` без такой
  опоры журналом НЕ считается (позитивный контроль `info-without-logging-import-is-not-a-log`).
- **Вывод мимо журнала — в границу с причиной «вне D-17».** `sys.stdout.write`, `sys.stderr.write`,
  `warnings.warn`, `traceback.print_*`, текст исключения: D-17 задаёт гейт списком получателей, и их
  расширение — решение владельца, а не правка гейта. Это граница рамки, а не слепота предиката, и шапка
  говорит именно так.
- **Начальные значения фабрики — тот же довод, что `bind`.** Значение, переданное фабрике именованным
  аргументом, уходит в каждую строку журнала; фабрика без них вызовом журнала не считается, поэтому
  живые числа не меняются.
