## Решения планировщика (Claude's Discretion CONTEXT)

- **Разбор — в отдельном модуле `wa_worker/own_phone.js` с внедрением `{ isPnUser, jidDecode }`**
  (RESEARCH Pattern 3, B10): `index.js` вызывает `main()` при ввозе, а `wa_worker/node_modules` локально
  пуст — настоящий Baileys в тесте не загрузить. Модуль ничего не ввозит; `index.js` подаёт ему
  настоящие функции пина.
- **Источник `me` в `/status` — `session.sock?.user`** (геттер Baileys `get user() { return
  authState.creds.me; }`, `socket.js:931-932`): `authState` в состоянии сессии воркера не хранится, а
  сокет — хранится. Пока `isConnected` истинно, `creds.me` уже заполнен (RESEARCH A2).
- **Тест — через `tests/conftest.py::run_node_script`**, а не раннер `node --test`: пропуск при
  отсутствии Node там запрещён (`pytest.fail`), и `just test` видит правило без второй обёртки.
  Вердикт гарнира — только булевы признаки по случаям, без цифр номера в выводе (Pitfall 8, ловушка
  `run_node_script` RESEARCH B10).
- **Ответ «сессии нет» поля `phone` не получает** (RESEARCH B5): приложению он не нужен, а старый и
  новый образ приложение читает одним кодом — отсутствие поля равносильно `null` (D-14).
