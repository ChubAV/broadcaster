# Фаза 03: отложенные находки

Обнаружено при исполнении планов фазы, вне их объявленного объёма. Не исправлено
намеренно: правка выходила бы за границы плана, в котором находка сделана.

## `GroupRepository` остался без потребителей (найдено планом 03-07)

**Где:** `app/repositories/group.py` (класс целиком), объявление протокола —
`app/domain/repositories.py:42`.

**Что:** после удаления `app/routes/groups.py` (план 03-07) у класса не осталось
ни одного вызывающего в `app/` и `tests/`:

```
grep -rn 'GroupRepository' app/ tests/
app/domain/repositories.py:42:class GroupRepository(Protocol):
app/repositories/group.py:7:class GroupRepository(BaseRepository[Group]):
```

Метод `list_by_user_filtered` использовался только удалённым JSON-входом списка;
`list_by_account` и `get_external_ids` не используются никем — экран групп
аккаунта и хелпер переинвентаризации собирают свои запросы напрямую.

**Почему не удалено планом 03-07:** объявленные файлы плана — `app/routes/groups.py`,
`app/main.py`, `tests/test_routes/test_groups.py`. Удаление слоя репозитория — не
следствие снятия GRP-08, а отдельное решение о структуре слоёв, и его цена
неизвестна до сноса глобального раздела `/groups` планом 03-08: тот работает с
теми же данными и может оказаться местом, где репозиторий уместнее ad-hoc
запросов.

**Кому адресовано:** решение принимать после 03-08, когда состав потребителей
данных о группах станет окончательным. Варианты — удалить класс вместе с записью
протокола либо, наоборот, перевести на него запросы экрана групп аккаунта.
