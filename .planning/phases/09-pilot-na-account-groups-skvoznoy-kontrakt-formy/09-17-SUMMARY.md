## Что именно применено (ветвь `destroy-guard`)

Единственная добавленная строка кода — пятый метод объекта `x-data`
(`app/templates/components/modal.html`):

```js
destroy() { if (this.open) { this.open = false; document.documentElement.classList.remove('is-modal-open'); } },
```

- Страж `if (this.open)` НЕСУЩИЙ: без него снос ЛЮБОЙ ЗАКРЫТОЙ соседней панели — а он
  происходит при каждой подмене строки тумблером — снимал бы блокировку у ОТКРЫТОЙ.
- Форма стража повторяет ту, что уже стоит в `hide()`, и является её зеркалом: там ранний
  возврат (`if (!this.open) return`), здесь условие вокруг снятия. Ранний возврат `hide()`
  правкой НЕ ТРОНУТ — в области выражения его по-прежнему ровно один.
- Ни одного свойства сверх названного владельцем не добавлено.

Измерение области выражения `x-data` ПОСЛЕ правки (команда `<verify>` №5):

```
ветвь=destroy-guard подъёмов=1 снятий=2 страж hide()=1 страж сноса=1
```
